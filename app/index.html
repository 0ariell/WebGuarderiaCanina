Conexión con la web (GitHub)

Para que el botón Publicar actualice tu página, la app necesita una clave de GitHub. Se crea una sola vez y queda guardada solo en este celular.

  1. Entrá a github.com/settings/personal-access-tokens/new
  2. Nombre: App Inquietos. Vencimiento: el más largo que te deje.
  3. En Repository access elegí Only select repositories y marcá WebGuarderiaCanina.
  4. En Permissions → Repository permissions → Contents elegí Read and write.
  5. Tocá Generate token, copiá la clave y pegala acá abajo.
